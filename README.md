# 贪吃蛇 Snake Game

一个用 Pygame 实现的贪吃蛇游戏，支持经典模式、AI 观赏、PVP 对战等多种玩法，纯程序化音效合成，无外部资源依赖。

## 有趣玩法

### 经典模式
方向键控制蛇移动，吃食物变长，撞墙或撞到自己即结束。可在设置中开启穿墙模式（蛇从屏幕对面穿出）。

### AI 观赏模式
内置 BFS 寻路 AI 自动操控蛇吃食物。AI 会动态评估安全路径——**两阶段安全检测**：先检查吃完食物后是否还有足够活动空间，再模拟蛇身走 `body_len` 步不撞死。决策优先级：安全吃食物 > 跟随尾巴 > 朝最开阔方向走。支持穿墙模式下的曼哈顿距离计算，还会检测移动是否会"封死整行/整列"导致无路可走。

### PVP 碰撞模式
两人同屏对战：P1 用方向键，P2 用 WASD。双方按 P/R 准备后游戏开始。蛇头撞到对方蛇身即死亡，撞墙撞自己也死。支持自定义围墙、初始蛇长、食物数量、网格大小（20×20 到 40×40）。

### PVP 战斗模式 🔫
在碰撞模式基础上加入**子弹射击系统**：

- P1 按 `\` / P2 按 `F` 发射子弹
- 发射消耗尾部一格身体（蛇头只剩一格时无法发射）
- 子弹速度为蛇的 3 倍，命中对方扣一条命
- 每方多条命（可配 1-10），命耗尽或撞墙/撞自己即失败
- **长度碾压机制**：一方比另一方长出 N 格（可配 3-10）直接胜利
- 子弹命中检测做了防穿透处理（检查 3 个中间位置）

### 蛇身造型切换
三种可切换造型，在设置中选择后重启游戏生效：
- **经典方块**：等宽圆角矩形 + 转弯关节线
- **圆形拼接**：重叠圆形 + 转弯关节连接
- **分段胶囊**：粗线胶囊身 + 圆形填充 + 圆头蛇头

所有造型都有渐变着色（尾暗→头亮）和蛇眼（含瞳孔、随方向转动）。

### 程序化音效
全部音效通过 `math.sin` + `array` 实时合成，无外部音频文件：
- 吃食物：600→1200Hz 上升扫频音
- 游戏结束：400→80Hz 下降音
- 胜利：C5→G5 双音序列
- 菜单点击/确认/倒计时/游戏开始各有独特音效
- 支持正弦波/方波/锯齿波，带渐入渐出包络防爆音

### 丰富的自定义设置
每个模式可独立配置：速度（5 档）、围墙开关、初始蛇长、食物数量、网格大小。战斗模式额外支持生命数和长度碾压优势。音效/音乐开关及音量独立调节。**设置延迟批量保存**：只在退出设置界面时写入磁盘。

### 视觉体验
- 页面切换 300ms 淡入淡出过渡动画
- 菜单项选中动画（颜色渐变 + 圆角卡片背景）
- 食物脉冲发光效果（sin 振荡 ±12%）
- 得分浮动 +1 文字（alpha 衰减上升）
- 游戏结束画面：先捕获最后一帧画面 + 半透明帷幕覆盖
- F11 全屏切换，支持 Pygame SCALED 缩放

## 架构

```
snake.py  (~2680 行单文件)
├── 常量区          — 窗口、网格、速度预设、颜色
├── 字体加载        — 中文 CJK 字体自动探测（支持 PyInstaller 打包）
├── 音频系统        — 程序化合成: _make_tone / _make_sweep / _make_victory 等
├── SettingsManager — JSON 持久化, 管理所有模式的速度/音效/音乐设置
├── SoundManager    — 封装音效播放, 跟随设置开关和音量
├── HighScoreManager— 最高分读写（单行文本）
├── Snake           — 蛇实体（移动/碰撞/3种造型渲染/蛇眼绘制）
├── Food            — 食物实体（随机放置避开占用格/脉冲光渲染）
├── Bullet          — 子弹实体（3倍速移动/带辉光渲染/防穿透）
├── ScorePopup      — 浮动得分文字动画
├── Menu            — 所有菜单/设置/HUD 界面渲染
└── Game            — 主控制器（状态机/输入分发/更新/渲染/主循环）
```

### 状态流转

```
MENU ──→ CLASSIC ──死亡──→ GAME_OVER
  │        │
  ├──→ AI 观赏 ──死亡──→ GAME_OVER
  │
  ├──→ PVP_SUBMENU ──→ PVP (碰撞) ──死亡──→ GAME_OVER
  │                    │
  │                    └──→ PVP_BATTLE (战斗) ──死亡──→ GAME_OVER
  │
  ├──→ HELP / SETTINGS / HIGH_SCORES
  │
  └──→ 退出
```

### 关键设计决策

| 决策 | 说明 |
|------|------|
| 单文件 | 所有代码在 `snake.py`，零模块引入开销，方便分发给他人 |
| 程序化音效 | `array + math.sin` 合成，不依赖外部 .wav/.mp3 文件 |
| 方向队列 | `dir_queue` 最多 3 个缓冲，防止快速按键丢失输入 |
| 游戏/渲染解耦 | 游戏逻辑按速度 FPS 运行，渲染和输入始终 60 FPS，带 500ms 上限防跳帧 |
| 防穿透 | 子弹 3 倍速移动时检查 3 个中间位置，避免穿过蛇身未检测到 |
| PVP 自适应窗口 | PVP 窗口尺寸 = cell_size × grid_size，退出自动恢复 |
| 过渡动画 | `_change_screen()` 10 帧 alpha 混合，`_game_just_ended` 先捕获画面再过渡 |

## 可学习的点 / 经验

### BFS 寻路与 AI 决策
- `_ai_bfs()` — 标准 BFS 找最短路径，处理穿墙和蛇身占用（考虑即将离开的尾部）
- `_ai_flood_fill()` — BFS flood fill 评估连通空间大小
- `_ai_is_path_safe()` — **两阶段安全检测**：先检查空间余量（可达空格 >= 蛇身长 × 1.2），再动态模拟蛇身走 `body_len` 步确保不撞死
- `_ai_would_seal()` — 检测移动是否会封死整行/整列（蛇身形成不可穿越的墙）
- 决策逻辑：安全吃食（70%概率出击增加观赏性） > 跟随尾巴 > 朝最开阔方向

### 程序化音频合成
- 使用 `array.array('h')` 构建 PCM 16-bit 样本 → `pygame.mixer.Sound(buffer=...)` 创建声音
- 渐入渐出包络避免爆音（前/后 10% 做线性淡入淡出）
- 扫频音：频率从 f_start 线性过渡到 f_end
- 支持正弦波、方波、锯齿波三种波形

### 状态机模式
- 主菜单、经典/PVP/战斗、设置、帮助等 10+ 个状态
- `_change_screen()` 统一管理状态切换和过渡动画
- 输入/更新/渲染三大函数根据当前状态分发到对应 handler

### 输入缓冲
- 方向输入用 `dir_queue`（最多 3 个），每帧 `move()` 消费一个
- 反向检测对比队列最后一个方向而非当前方向，避免队列堆积时原地掉头

### 增量时间游戏循环
- `RENDER_FPS = 60` 固定渲染帧率
- 游戏逻辑移动以可变间隔驱动：`move_interval = 1000 / speed_fps`
- 累加器防跳帧上限 500ms，切窗回来不会瞬间死亡

### 设置持久化
- JSON 文件 + 默认值合并（`dict.update`），升级新增设置键时不会崩溃
- 修改只改内存（`set()`），离开设置界面时才调用 `_save()` 批量写入磁盘

### Pygame 渲染技巧
- `pygame.SRCALPHA` Surface 做辉光、半透明帷幕、alpha 过渡
- 蛇身渐变：`ratio = i / len(body)` + darken 系数动态调暗尾部
- 转弯关节：用线条连接相邻格，再在上面叠加方块/圆形，隐藏穿屏线（跳过跨度 > 1 的段）
- 游戏结束画面：`screen.copy()` 捕获当前帧，再叠加半透明黑色遮罩

## 技术细节

### 环境要求

| 项目 | 说明 |
|------|------|
| Python | 3.6+（无版本特定语法，3.6 即可运行） |
| 依赖 | `pygame` 仅此一项，无其他外部库 |
| 标准库 | `random` `sys` `os` `json` `math` `array` `collections.deque` |
| 平台 | Windows / macOS / Linux 均可运行 |

### 安装与运行

```bash
# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows

# 安装依赖
pip install pygame

# 运行
python snake.py
```

### Pygame 版本兼容

代码使用稳定的 Pygame 2.x API（`SRCALPHA`、`SCALED`、`mixer.Sound(buffer=...)`），兼容 Pygame 2.0 及以上版本。

- `pygame.SCALED` 全屏标志需 Pygame 2.0+
- `pygame.mixer.Sound(buffer=bytes)` 需 Pygame 2.0+

若遇到音频设备初始化失败（部分无音频设备环境），程序会自动降级为静音模式，不影响游戏运行。

### 打包为独立可执行文件

```bash
pip install pyinstaller
pyinstaller --onefile --add-data "fonts:fonts" snake.py
```

代码已内置 `sys.frozen` 检测，PyInstaller 打包后字体和路径正常工作。
